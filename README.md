TelzonOS 1.0

TelzonOS is a next-generation web-based operating system built entirely from scratch by Telzon™.
Powered purely by HTML5, CSS3 and JavaScript — no frameworks, no build tools, no installs. Open it in any modern browser and a complete mobile-style OS comes alive, instantly.

> "Think Your Own Way…"

---

🌐 What Can You Do With TelzonOS?

- Run a full OS in your browser — boot screen, lock screen, home screen, gestures, everything
- Enjoy buttery-smooth animations — icon-morphing app open/close transitions, live wallpaper zoom, liquid glass effects, all GPU-accelerated at up to 120 FPS
- Shoot real photos & videos — a working camera with zoom, multiple lenses, flash, focus tap and video recording
- Talk to TelzonAI — a Gemini-powered assistant with full voice mode: speak to it and it speaks back, in English, සිංහල or தமிழ்
- Lock any app — protect private apps with your own PIN
- Install new apps — browse the built-in TStore and install apps on the fly using Telzon's own `.tpa` package format
- Make it yours — wallpapers, themes, icon shapes, clock styles, lock screen layouts, haptics
- Install it as an app — add to home screen as a fullscreen PWA and launch it like a native app

✨ Features

🔐 Lock Screen & Security
- Swipe-up unlock with physics-smooth animation
- PIN lock (4 or 6 digits) and Password lock
- Brute-force protection — 60-second lockout after 6 failed attempts
- Per-app lock — lock individual apps with your PIN
- Always-On Display with double-tap to wake
- Customizable lock clock: size, weight, Liquid Glass effect, colors
- Lock screen shortcuts — Camera, Photos, Flashlight, Voice
- Notifications mirrored on the lock screen & AOD

🏠 Home Screen
- Signature hexagon glass icons on a multi-page grid
- Icon shape system — Hexagon / Round / Square / Flat / Mono
- Long-press app menus with info, features and uninstall
- Edit Home Screen mode — wallpapers, themes, one-hand mode
- Parallax wallpaper with smooth motion
- iOS-style icon-morph open/close animations (60–120 FPS)

🔔 System UI
- Control Center — Wi-Fi, Bluetooth, Cellular, Airplane, Torch (real flashlight on supported devices), DND, Rotation, brightness & volume sliders, resizable tiles
- Notification Center with media playback controls
- Recent Apps carousel with swipe-to-dismiss
- Haptic feedback throughout (`navigator.vibrate`)

📦 Apps (25+)
Phone · Messages · Camera · Photos · TMusic · Clock (Alarm / Timer / Stopwatch / World) · Notes · Mail · TStore · Calculator · Health · TPAY · Files · Calendar · TBrowser · Settings · Reminders · Habits · Goals · Drawing · Photo Editor · Visualizer · Video Player · Sticker · TelzonAI · WebIDE

💻 WebIDE
TelzonOS ships with its own in-browser development environment — write, edit and preview HTML, CSS and JavaScript code directly inside the OS. Build mini apps, experiment with UI, and test everything live without leaving TelzonOS. Perfect for learning, prototyping and quick creative coding on any device.

⚙️ Settings
- Telzon Account profile
- Wallpaper & Style, Dark / Light mode, Refresh rate (auto-adapt), Parallax wallpaper
- Battery Saver — Normal Mode reduces all animations in one tap
- Sounds, touch sounds, haptic intensity, animation speed
- TelzonAI API key management
- Apps manager with `.tpa` package installer

🧠 Smart Engineering
- Adaptive performance targeting 60 / 90 / 120 FPS based on device capability
- GPU-first rendering — transform & opacity-only animations, `will-change`, `contain`, `content-visibility`
- Normal Mode battery saver
- Persistent storage — all settings survive restarts
